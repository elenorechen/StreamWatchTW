# 刷瓜小幫手（Stream Watch 台灣中文版）

刷歌手機上的音樂 App 停止播放時，通知你的**刷歌手機、日常手機和電腦**。

> 靈感來自韓國 PLLI 製作的刷歌監控 App，這是重新寫的繁體中文版本。
> 非營利、粉絲自製，可能會有 bug，覺得不好用可以不要用 🙏

- ✅ 支援 Melon、Genie、Bugs、FLO、VIBE、Spotify、YouTube Music、Apple Music、KKBOX 等（只要是會在通知列顯示播放控制的音樂 App 都可以）
- ✅ 停止、緩衝太久、App 被關掉時通知
- ✅ 充電線鬆脫、電量過低時通知
- ✅ 透過免費的 ntfy 傳到日常手機和電腦
- ❌ **不會**自動幫你恢復播放，只負責提醒
- 只支援 Android 8.0 以上（刷歌手機要是 Android）

---

## 一、安裝到刷歌手機

1. 到本頁右側的 **Releases**，下載最新的 `StreamWatchTW-x.x.x.apk`。
2. 用刷歌手機打開 APK 安裝。
   - 如果跳出「Play 安全防護」擋下來，可以先到 Play 商店 → 右上角頭像 → **Play 安全防護** → 右上角齒輪 → 暫時關閉「使用 Play 安全防護掃描應用程式」，裝完再打開。
   - 如果問「是否允許安裝不明來源的 App」，選允許。

## 二、在刷歌手機上設定

打開「刷瓜小幫手」，最上面的黃色框會列出還沒完成的設定，照順序按「去設定」：

1. **通知存取權**：找到「刷瓜小幫手」並開啟。
   - **開關是灰色、按不下去？** 這是 Android 13 以上對「非 Play 商店安裝的 App」的保護。到手機的 **設定 → 應用程式 → 刷瓜小幫手**，按右上角 **⋮ → 允許受限制的設定**，再回來開啟就可以了。
2. **允許通知**：按「允許」。
3. **電池不要最佳化**：按「允許」。這一步很重要，不然手機休眠時監控可能會被系統停掉。
   - 小米、OPPO、vivo、三星等手機另外還有「自動啟動」「背景耗電管理」，建議也把刷瓜小幫手設成不限制。

接著：

4. 按「**＋ 選擇要監控的 App**」，勾選你用來刷歌的音樂 App（★ 是常見的音樂 App）。
5. 按「**▶ 開始全部監控**」。每個 App 會出現一張狀態卡。

### 狀態卡

| 狀態 | 意思 |
|---|---|
| 播放中 | 正在播放 |
| 緩衝中 | 正在載入或等待網路 |
| 停止 | 暫停、停止或播放錯誤 |
| 無法確認 | 讀不到播放狀態，App 可能被關掉了 |
| 暫停監控 | 你暫停了這個 App 的監控，不會通知 |
| 等待開始 | 還沒按「開始全部監控」 |

- 「緩衝中」「停止」「無法確認」持續超過設定的時間（預設 30 秒）就會通知。
- 第一次通知後，每隔一段時間（預設 5 分鐘）再提醒一次，預設會**一直提醒到恢復播放或按「知道了」**，也可以在設定裡改成最多幾次。
- 每次提醒都會重新跳出來，不會只是安靜地更新上一則通知。
- 按通知上的「**知道了**」，或音樂恢復播放，就會停止提醒。
- **暫停監控**：這個 App 停了也不會通知。打開「恢復播放時自動重新監控」，它一恢復播放就會自動重新開始監控。

這些時間都可以在「通知設定」裡改。

## 三、在日常手機收到通知（選用）

刷歌手機和日常手機是同一支的話，這步可以跳過。

1. 在刷瓜小幫手的「傳送到日常手機和電腦」打開「**傳送通知到其他裝置**」。
2. 按「**傳給自己**」，用 LINE「Keep 筆記」、Messenger 傳給自己、Email 等方式，把連結代碼傳到日常手機。
   - ⚠️ 不要手打代碼，也不要用截圖辨識文字，很容易打錯。
3. 日常手機安裝 **ntfy** App（[Android](https://play.google.com/store/apps/details?id=io.heckel.ntfy) / [iPhone](https://apps.apple.com/app/ntfy/id1625396347)）。
4. 打開 ntfy → 按「**＋**」→ 主題（Topic）貼上 `plli-` 開頭的代碼 → 伺服器用預設的 `https://ntfy.sh` → 訂閱。
5. 回到刷歌手機按「**遠端通知測試**」，日常手機收到就成功了。

## 四、在電腦收到通知（選用）

1. 用 Chrome 或 Edge 打開刷瓜小幫手上顯示的網址（`https://ntfy.sh/plli-xxxx`，也在「傳給自己」的訊息裡）。
2. 網頁問要不要顯示通知時，按「**允許**」。
3. 這個分頁保持開著（可以縮小，但不要關掉）。
4. 在刷歌手機按「遠端通知測試」確認電腦有跳通知。

## 電腦版：Melon 網頁版監控（Chrome 擴充功能）

在電腦上用 **Melon 網頁版**刷歌的話，可以安裝電腦版。Windows、Mac 都能用，支援 Chrome 和 Edge。

**安裝**

1. 到 **Releases** 下載 `StreamWatchTW-Chrome-x.x.x.zip`，解壓縮，得到 `StreamWatchTW-Chrome` 資料夾。
   - 把這個資料夾放在不會被刪掉的地方（例如「文件」），之後不要移動或刪除，不然擴充功能會消失。
2. Chrome 網址列輸入 `chrome://extensions`（Edge 輸入 `edge://extensions`）。
3. 打開右上角（Edge 在左下角）的「**開發人員模式**」。
4. 按「**載入未封裝項目**」，選剛剛的 `StreamWatchTW-Chrome` 資料夾。
5. 按網址列右邊的拼圖圖示，把「刷瓜小幫手」釘選出來。

**使用**

1. 開啟 Melon 網頁版開始播放。
2. 按工具列上的刷瓜小幫手圖示 →「**▶ 開始監控**」。
3. 圖示上的小標籤會顯示狀態：綠色 `ON` 播放中、紅色 `!` 停止、紅色 `?` 找不到 Melon 分頁。

想讓手機也收到通知：打開「傳送通知到手機」，把手機版刷瓜小幫手的連結代碼貼進「連結代碼」，電腦和刷歌手機的通知就會傳到同一個 ntfy 主題。

**注意**

- 電腦休眠、瀏覽器整個關掉時沒辦法通知。請到 Windows「設定 → 系統 → 電源」把「睡眠」設成「永不」。
- 用「開發人員模式」安裝的擴充功能，Chrome 有時會跳出提醒，選擇保留即可。
- 更新：下載新的 zip，覆蓋原本的資料夾，再到 `chrome://extensions` 按刷瓜小幫手的「重新載入」↻。

## 🔒 安全說明

- **連結代碼不要公開**。ntfy 是公開服務，知道代碼的人都能收到（也能發送）你的通知。代碼外流的話，到「進階 → 重新產生連結代碼」換一組新的。
- 「通知存取權」技術上可以讀到所有通知，但刷瓜小幫手**只讀取音樂 App 的播放狀態**，不會讀取、保存或傳送其他通知內容。原始碼都在這個專案裡，可以自由檢查。
- 送到 ntfy 的內容只有：App 名稱、狀態、停了多久、你設定的手機名稱。
- 建議把刷瓜小幫手裝在**專門刷歌的手機**上，不要裝在有網銀或重要資料的主力手機。

## 常見問題

**一直顯示「無法確認」？**
音樂 App 沒有在播放或被系統關掉了。先在音樂 App 按一次播放，狀態就會更新。如果音樂明明在播還是顯示無法確認，把通知存取權關掉再打開一次。

**手機鎖螢幕之後就沒通知？**
檢查「電池不要最佳化」有沒有完成，以及手機品牌自己的背景限制（自動啟動、省電模式）。

**會不會很耗電？**
監控中會讓手機的 CPU 保持醒著（螢幕不會亮），刷歌手機本來就接著充電的話影響不大。按「停止全部監控」就會釋放。

**可以同時監控好幾個 App 嗎？**
可以，每個 App 各自計時、各自通知。
